A note's lock pins the card in place and nothing more — a locked note is still
typed into, renamed, recoloured and hidden; only moving and resizing are
refused. The eye is on every card now, so hiding a note is one press instead of
a trip through the file menu. And a card whose file cannot be read keeps what
you had typed on screen instead of blanking, while a note's path is recorded
only once its first save has actually landed — a write that never lands no
longer leaves a card pointing at a file nobody created.
