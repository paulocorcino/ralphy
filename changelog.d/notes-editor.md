Write a note on the consoles stage: markdown that renders as you type — Notion
style, with a slash menu, task lists and tables — autosaved into an opaque
`.note` file in the project you are working in. A note names its own file from
its first heading, picks a colour that travels with the file, opens links into
the workbench, and gives its editor back while it is off-screen.
