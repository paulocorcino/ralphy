headline: 🖥️ **Hosts** — your hosts in one list, to edit a connection or remove a host
---
The Hosts dialog lists the hosts reached over SSH. Edit changes the address, port, user or key file of a host, and its connection opens again at once. Remove moves into the list. Every group in the Projects list shows the icon of its system: Linux, macOS, Windows or other.
