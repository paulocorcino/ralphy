Notes keep what you typed: the last character before a close, a `Ctrl+S` or a
tab closing is no longer lost to the editor's own change notification arriving
late, two saves of one card can no longer land out of order, and a note is
named once instead of leaving an orphan file behind. A note also opens where
the card can be used — in edit, outside any fence, centred by the map — and the
card's file menu no longer hangs open over the text.
