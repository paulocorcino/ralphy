          Security
          opt-in — the daemon is open on localhost and locks down only when you ask
          
          
        

        

          
          

            

               Access token
              
            

            

              A machine credential for reaching the daemon over the network. It also signs your
              browser session. Re-minting it logs every session out — including this one.
            

            

              
            

          


          
          

            

               Login password
              
            

            

              Optional extra factor on top of 2FA (PBKDF2). Enter it twice to save; a new value
              replaces the old.
            

            

              
              
              
              
            

            

              Passwords don't match.
            

          


          
          

            

               Two-factor (TOTP)
              
            

            

              Codes from any authenticator app (SHA1 · 6 digits · 30s). Scan the QR, then enter a
              code to confirm — enrolment only completes once you prove you scanned it.
            


            
            

              
            


            
            

              

              

                
 Shown once — scan or copy it now.

                
                
                
                

                  
                  
                  
                

                

              

            


            
            

              Enrolled. The secret can't be shown again — revoke to start over.
              
            

          


          
          

            

               Require login
              
              
            

            

              Gate the browser UI behind a login screen. Needs 2FA enrolled first. With it on,
              the daemon logs you off and stays locked until you log in.
            

            

              Enroll two-factor above to enable this.
            

          

        

        

          Password / TOTP / token are stored and validated by the daemon.
