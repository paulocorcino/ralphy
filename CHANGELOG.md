# Changelog

Generated by `cargo run -p xtask -- changelog --release <version>`, which folds
`changelog.d/*.md` into it. Edit a fragment, never this file (ADR-0056 §2).

Releases cut before the first entry below predate this record and are on the
[Releases page](https://github.com/paulocorcino/ralphy/releases).

## v0.1.0-rc.39 — 2026-10-05

### New

- Desk history keeps the last 50 layouts of your consoles: in Settings, restore one, download it as a file, or upload a file.
- A detached fence window can open its consoles as columns and keep a note on top.
- Settings → Devices lists each browser that connected, with its system, public address, and the changes it made.
- A console that is not running shows its Relaunch button in a detached fence window too.

### Fixed

- On Windows, a peer whose daemon is stopped is reported after 1 second instead of 2, always as a failed connection. (#536)
- After a reload, a console off the screen connects only when you scroll to it, so a reload no longer downloads the text of every console.
- Opening the workbench on two devices at once no longer starts each console twice or moves consoles out of place.
- Consoles keep their saved places when the page could not read the desk at first, for example right after the host wakes up.
- A change made on one device is no longer undone by another device that was open at the same time.
- A desk with many consoles on the screen no longer loses the fast renderer on some of them after a reload.
- When another computer stops answering, its consoles and file list say why and wait, then come back when it does.
- A console on another computer is no longer started a second time when that computer does not answer during a page load.

## v0.1.0-rc.38 — 2026-10-04

- A console that reconnects no longer types a stray `R` at the shell prompt.

### Fixed

- The workbench says when it could not read a fact, keeps the last value marked as old, and reloads after an update. (#511)

- A run that resumes a finished plan now checks and closes the issue instead of marking it as needing a split.

## v0.1.0-rc.31 — 2026-09-30

### Security

- The daemon can ask for its access token also on 127.0.0.1 (`ralphy daemon require-token on`), and on Windows its token and stores are now readable by your account only. `ralphy daemon setup --name --avatar` sets the name without questions. (#494)

### New

- A peer descriptor can name an SSH tunnel: the daemon keeps one `ssh` local forward open to that host, shows the host as `<name>: <OS>` in the sidebar, says whether the tunnel is closed or the host daemon does not answer, and runs free consoles on the host. (#495)
- `ralphy host add <host>` makes a computer you reach over SSH a peer: it checks the host, turns on its access token, and writes the tunnel, so the host's repos appear in the workbench. `ralphy host check` shows what is missing, and `ralphy host remove` takes the host out. (#496)
- The workbench can add a computer you reach over SSH from the Projects header. It lists your SSH config hosts, confirms the host key, shows the host checks, and connects. The group menu can remove the host. (#497)
- The Add a host dialog can sign in with the account password. Ralphy uses it once to add its own key on the host, then forgets it, so the next connections need no password and nothing is typed in a console. (#498)
- When Ralphy is missing or too old on a host, the Add a host dialog can install this computer's version there over SSH, in a folder of your home, with no administrator. It never installs an older version than the one on the host. (#499)
- The Add a host dialog is shorter: Host and Port, then User and Password, and the browser no longer offers to save the password. The host checks show one thing to do at a time, with the passed checks folded into one line.
- Columns can now hold consoles one above the other. The title bar button is now "Slice": pick Right to open a new column, or Down to open the console below the one you are in. Alt+Shift+↑/↓ moves between the rows of a column.
- The file tree draws the files and folders your repo ignores in a faded tone, as VS Code does. You can see what is outside the repo without opening `.gitignore`.
- The What's new panel has an Update now button. Ralphy downloads and checks the new release, restarts, and the page loads again. On Windows it then updates the WSL copy too. If the new version does not start, the previous one comes back.

### Fixed

- A dialog no longer closes when you click outside it. A stray click lost what you had typed in Settings or Add a host. Close a dialog with its ✕, its buttons, or Escape.
- The Start a run dialog is narrower now. It was drawn as wide as the large dialogs, so its short form stretched across the screen.
- The update question in What's new lists the consoles that close on this computer. It says apart that the WSL consoles close only if the WSL copy takes a new version.
- `ralphy update` and `ralphy daemon restart` now restart a daemon that runs as a systemd service through systemd. Before, they stopped it in a way that systemd reads as a crash.
- The What's new panel says how many consoles are open, because the update closes them and stops their agents. It shows the update command with a copy icon and a "Check for new releases" checkbox.

## v0.1.0-rc.29 — 2026-09-28

### New

- A maximized console can open other consoles beside it as columns of equal width. Pick a console from the list in its title bar. Restore removes one column. The number of columns follows the screen width and the font size. (#472)
- Columns come back after a reload of the same browser. A column that does not fit a narrower screen is kept and comes back when there is room. Alt+Shift+←/→ moves between columns. A console closed or detached elsewhere leaves the columns. (#473)
- Every console now has a short name, such as fincal #1, shown in the column list, the Go-to list and its title bar, next to its repo. Double-click the name to change it. The name stays after a restart and is the same in every browser. (#479)
- When the Claude console name setting is on, Claude now takes its session name from the console name: fincal #1 starts as wb-fincal-1. Other Claude sessions reach it by the name you read in the title. (#480)
- A column can swap its console at any time, even when no more columns fit. The swap icon on a row of the column list puts that console in the column. The console that was there goes back to its place and keeps running.
- Open a console that runs a command you type, such as `htop` or `ping`: use Run… on the console row of the Consoles menu, or press Alt+Shift+R. It replaces the "Console startup command" setting.
- A note shows "Add title" on the empty line where you write. One click makes the line a title, and "Remove title" makes it plain text again. You do not need to know that `## ` starts a title.
- Keep a note on top: from the Note menu, its card floats in front of your consoles, even a maximized one, and goes back to its place when you put it back.
- Choose to show web images, such as badges, in markdown previews: turn on Remote images in Security settings. It is off by default, and a blocked image now shows a short note instead of a broken icon.
- On a touch screen, the console font now starts at 14px instead of 15px, so a landscape iPad has room for two columns. A font size you chose before stays as it is.

### Fixed

- On Windows, Ralphy now refuses to start an agent through a `.cmd` program when the Windows command processor would misread its command line: a path or setting holds `&`, `%` or a similar character, or the program's folder has a space and an argument needs quotes. (#481)
- The workbench file tree stays live when the connection to the daemon drops and comes back, and it shows files that changed on a peer machine while that peer was down. (#484)
- Escape now closes the Settings and Security windows, like every other workbench window. A window puts the keyboard in its first field when it opens and gives it back to where you were when it closes, so you can type in a console again at once. (#487)
- On a phone, a board column now fills the screen. A swipe moves one column, and the edge of the next column shows that there are more.
- Clicking an image in the Changes panel now shows the image. Before, a tab opened and closed at once. Other binary files now show a clear message and open no tab.
- When you stage, unstage or discard a file that has no change anymore, for example because it was committed in a console, the message now says that the file has no change and may be committed already, instead of "not in the change set".
- Checkboxes in the workbench now use its dark colors. An empty checkbox was a white box.
- The list that opens a column is shorter and easier to scan. A repo shared by a group is shown once. A long list has a filter box.
- The column list stays inside the window, even with long rows near its edge. It shows each repo without its environment.
- When you restore a column and one console is left, that console stays on top. Before, the restored console was drawn over the maximized one.
- A maximized console no longer shows the lock and close buttons, so a stray click cannot end a working agent. Restore it first to close it. In full screen, the console shows only the exit and restart buttons.
- Alt+Shift+R and Alt+Shift+0 to 9 now open a console when a terminal has the focus, and Alt+Shift+R from another tab shows the Consoles tab with its menu. Before, these keys did nothing in both cases.
- Some workbench texts now use common words instead of technical terms. For example, closing or restarting a console says "You lose the text in this console" instead of "Scrollback is lost", and Spend says "The real cost can be higher" instead of "Lower bound".
- A console's title bar now has the same height as the project row beside it, so their bottom lines stay on one line. Before, the project row got shorter when the project had no changes.
- Closing a detached file window now brings the file back to the workbench, with its unsaved edits, the same as the Re-attach button. Before, closing the window lost the tab and every edit that was not saved.
- With a console maximized, choosing a fence no longer moves the view behind it. The fence still takes the focus, so the next console opens inside it.
- Detaching a fence again right after you bring it back no longer closes the new window, and the closing window can no longer take consoles out of the new one.
- `ralphy --help` lists the commands in the order you use them, with a short line for each, and puts the commands that the workbench and the agents run in their own list at the end. Every command's help is now in plain words.
- On a phone, the board search now takes the whole top row while you type. The plan chip shortens its text, so refresh and close stay on screen, and the Backlog sort menu stays inside its column.
- Help text, log lines and error messages are written in plain English and no longer cite design records (ADR numbers) that mean nothing to someone who runs Ralphy.
- A new note that you have not saved yet keeps its text when you detach its fence, and the file the detached window saves is linked back to the note on the workbench.
- The Note menu lists your notes and nothing else. To go to a title inside a note, use the list button in the note itself.
- A note kept on top stays editable when you leave it alone. Before, it could turn into a faded title after some time, until you put it back.
- Put back returns a note behind a maximized console again. Before, a note you had typed in stayed in front of the console after you put it back.
- On a phone, the file editor toolbar now gives its row to the buttons. The tab already names the file. In the contents list, a long heading wraps instead of being cut.
- The branch next to a project name now follows a branch switch or a commit made in a console or in another terminal. It updates within a second, with the Changes list, and you do not need to open Changes first.
- In the Changes panel, a branch with no upstream now shows a "Publish branch" button in place of "Push". The button pushes the branch and sets its upstream. Pull is hidden for that branch, because there is nothing to pull from yet.
- The run picker card is now aligned. The agent and phase line starts at the left edge under the model name, and the progress count sits right above the phase clock.
- The Security window shows its password fields again, so you can set, change or remove the daemon login password from the workbench.
- Stop now also stops a run while it is planning an issue. Before, the Claude planner kept running until it finished its plan, and a stop during planning could end the run with a planning error instead of as a stopped run.
- The read-only strip on a console that another window controls now says only "Read-only. Another window has control." It no longer repeats the agent and the repository, which the title bar already shows, so the strip fits on a phone.

## v0.1.0-rc.25 — 2026-09-23

### New

- The workbench loads faster over a tunnel and reloads for free: every asset carries a content ETag so a reload is a round of 304s, and text assets go out gzipped (11 MB down to 3 MB on first open).
- Open a console that starts straight into a command of your choice — `htop`, `btop`, `lazygit`… Set it once under Settings → Consoles and it joins the New console menu (Alt+Shift+9); the console closes when the command exits.
- The workbench opens, searches and saves text in any encoding (Windows-1252, UTF-16, …), names it on the file tab with "reopen with…" and "save with…", and keeps a refused file's tab open with the reason instead of closing it.
- Write a note on the consoles stage: markdown that renders as you type — Notion style, with a slash menu, task lists and tables — autosaved into an opaque `.note` file in the project you are working in. A note names its own file from its first heading, picks a colour that travels with the file, opens links into the workbench, and gives its editor back while it is off-screen.
- A `.note` in the file explorer opens as its card on the consoles stage — and jumps to it if the card is already there, rather than opening a second editor over one file. The card can rename or delete its own file, and a note whose file has gone says so and can be pointed at another one instead of quietly disappearing.
- A note card is written in a hand and a size of your choosing — sans, serif or mono, in five steps — chosen from the palette and kept in the file, so a note comes back in its own hand when you open it again. The file's own menu moved out of the card's titlebar into a gear in the footer, beside the path it acts on, and hiding a note is the eye's job alone now.
- The Note menu is a map: every note on the plane is a row that slides the view to its card, and a note's own `##` sections hang under it — collapsed — so a long note is one click from the part you meant.
- A ```mermaid fence inside a note draws the diagram, and clicking it opens a small editor over the drawing with a live preview — Ctrl+Enter applies, Esc cancels. Mermaid diagrams also get their labels back everywhere in the workbench, including the file viewer: the sanitizer had been removing them.
- A note can be marked to open hidden: the eye in the card's head writes the mark and shows the note for this session only, and a hidden card mounts no editor at all — the text is never put on the page, just the eye in the middle of it. A guard against the room rather than encryption; the file is obfuscated, not secret.
- Open a second file beside the one you are reading, or mirror the same file into a second editor with its own scroll and cursor; the arrangement follows this browser across reloads.

### Fixed

- The Changes panel now names the worktree it reads, with the same chip and picker as the Files bar, so the selected tree is visible without leaving the panel.
- The Changes panel shows when a fetch, pull or push is still running: the busy button spins and the remote bar locks until the upstream answers, so a slow push no longer looks like a dead click.
- A console comes back after a network switch or a long stretch in the background, even behind a tunnel, instead of closing or asking you to take it over.
- After a daemon restart, an old console window can no longer reattach to a different session, and the restarted daemon keeps writing to `daemon.log`.
- The New console menu is a launcher again: every row opens a new console on click (the live count stays as a readout), the head names the repo by its bare name, and the accelerator pattern is stated once with each row carrying only its digit.
- The workbench no longer keeps a password field in the page when nothing is asking for a password: the login gate's and the settings modal's are rendered only while those surfaces are open. Typing in any other field — renaming a note, for one — stopped making the browser offer to save what you typed as a password.
- A note card can be typed into wherever it sits: a card restored beside a console was drawn under it and the keystrokes went to the shell. The card also wears the plane's own chrome now instead of text glyphs, its title is renamed by clicking it, and its ground and its text colour are chosen separately — a solid tone with a light ink is a yellow note with white writing on it.
- A note card is a card, not a page. Its editor's toolbar and slash menu are sized for a 320 px note instead of a full document and their icons are drawn in a colour you can see; headings look like headings again; bullets, numbers and task checkboxes appear at all; the `+`/`⠿` block handle that had nowhere to sit is gone (`/` opens the same menu); a click on the blank space below the last line keeps the caret instead of dropping the next keystrokes; and pressing Enter reads as the next line rather than a gap. A note's title now lives in the file's header instead of being repeated as a heading at the top of the body — existing notes keep their name and are migrated the first time you rename one. A mermaid diagram applies what you typed into it, says so when it is still empty, and no longer leaves its error cartoon on the plane.
- Picking a section from a note's index scrolls the note to it and leaves the canvas where it was — the plane no longer pans out from under the card.
- Links in a note are typed, readable, and reachable: `[text](url)` and the `@@path/to/file` shorthand now make one as you type, a link follows the card's own ink instead of a fixed colour that was unreadable on a filled card, and the hover preview no longer prints the path in the card's ink on the plane's dark chrome. A card's footer also says when the note was last saved, and the close toast names the file once.
- A note's lock pins the card in place and nothing more — a locked note is still typed into, renamed, recoloured and hidden; only moving and resizing are refused. The eye is on every card now, so hiding a note is one press instead of a trip through the file menu. And a card whose file cannot be read keeps what you had typed on screen instead of blanking, while a note's path is recorded only once its first save has actually landed — a write that never lands no longer leaves a card pointing at a file nobody created.
- A note card says what to type: the footer's gear → `Markdown help` lists the marks the editor understands (CommonMark + GFM, including a ```mermaid fence that draws), `[ ]` on a plain line now makes a task instead of literal text, the head gained an index of the note's `##` headings, an empty heading reads "Write a title", the scrollbar fades out when the card is not in use, and a new note is born in the operator's colours.
- A mermaid diagram in a note is drawn on the card instead of in a dark box cut out of it: its nodes, edges and labels are mixed from the card's own ground and ink, so it reads on any tone — and restyling the note repaints the diagrams in it.
- Notes keep what you typed: the last character before a close, a `Ctrl+S` or a tab closing is no longer lost to the editor's own change notification arriving late, two saves of one card can no longer land out of order, and a note is named once instead of leaving an orphan file behind. A note also opens where the card can be used — in edit, outside any fence, centred by the map — and the card's file menu no longer hangs open over the text.
- Keeping a WSL distro awake no longer opens an empty `wsl.exe` terminal tab on Windows.

## v0.1.0-rc.23 — 2026-09-21

### Security

- Closes the 2026-09 security audit: workbench file writes can no longer reach `.git` or `.ralphy` under any spelling, issue comments from non-collaborators no longer reach the agent, and lowering your own login posture now costs a fresh factor.

### New

- The console works from a phone: a maximized console takes the whole screen, the key bar gains paste and a drag-to-select-lines mode, and copy wears a copy icon.
- Lock a console or a fence in place from its title bar so a slipped finger on a tablet cannot move it, and a tap on a title bar no longer counts as a drag.
- A desk full of consoles stays fast: a console scrolled well off the viewport puts its terminal to sleep and gives its renderer back, and repaints from the daemon's scrollback the moment it comes into view again.

### Fixed

- A console no longer comes back twice when the workbench is open on more than one device: a page merges the desk with what the other pages saved before it writes, and a session whose record lost its id returns to its own window instead of a new one beside it.
- The workbench reads on a phone: a file's toolbar names only its path, its controls stay reachable, a Markdown document's index folds into an overlay you open when you want it, an issue on the board opens across the whole pane with a back arrow instead of a close button that had scrolled out of reach, and a console's title bar and the board's header stay one row with their close buttons in reach.
